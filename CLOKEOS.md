# ClokeOS changes

This branch holds the changes [ClokeOS](https://github.com/cloke-tech/ClokeOS) makes on top of Raven (base: `387c718`).
It is a fork used by ClokeOS; thank you to the original authors. The changes follow the licence of the upstream project.
Patch files and the build scripts that apply them live in ClokeOS under `clokeos-darwin/raven/`.
Port of Raven from Linux to XNU/Darwin (x86_64): Mach gate, toolchain file and a patch set (see docs/raven-port.md in ClokeOS).
